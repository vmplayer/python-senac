# Módulo 02 — Programação Orientada a Objetos

Neste módulo, vamos organizar programas Python usando classes e objetos, reunindo dados e comportamentos relacionados.

**Pré-requisitos:** variáveis, tipos de dados, entradas, condicionais, repetições e listas do [Módulo 01](../Módulo%2001/README.md).

## Aulas disponíveis

- [Tópico 01 — Introdução à Programação Orientada a Objetos](01%20-%20Introdução%20à%20POO.md)

## Sequência prevista

1. Classes, objetos, atributos, métodos e estado.
2. Encapsulamento, validação e propriedades.
3. Composição: objetos que trabalham com outros objetos.
4. Herança e polimorfismo.
5. Projeto integrador com POO.

A primeira aula apresenta também `def`, parâmetros e `return`, necessários para escrever os métodos. Os demais tópicos serão desenvolvidos nas próximas aulas.
